# よくある質問

[English](FAQ.md) · [導入手順](README.ja.md)


**無料ですか？** コードはApache-2.0、キャラクター素材はCC BY 4.0です。AI提供元のアカウントや利用料金は別です。

**オフラインで使えますか？** 会話や作業コピーはローカル保存ですが、実際のCLIはコードや依頼をAI提供元へ送信する場合があります。

**対応環境は？** 対応表のmacOS Apple SiliconとCLIバージョンです。署名済みインストーラーはありません。Windows・Intelの実行は未対応です。

**Live2Dですか？** PixiJSによる描画です。Cubismモデルではありません。

**ステッカーを押すと実行されますか？** いいえ。依頼文を編集してから送信します。実行承認も省略しません。

**質問や不具合報告は？** 公開後は、秘密情報を除いた再現手順を英語・日本語のIssueでお知らせください。脆弱性や個人情報を含む報告は公開Issueに書かず、公開された専用窓口をご利用ください。

セキュリティ・行動規範に関する報告：[coipoddev@gmail.com](mailto:coipoddev@gmail.com)。英語・日本語で受け付けます。パスワードやAPIキーは送らないでください。
