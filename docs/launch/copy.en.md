Title: I built a character-based workspace for AI coding CLIs

I'm building COI, an open-source desktop workspace with a character companion. It connects supported Codex, Claude Code and Antigravity CLIs. The stickers help write a request; they don't send it automatically. Changes happen in a working copy and need a separate review before application to the originals.

The interface supports English and Japanese. This is a development alpha: real execution is limited to the validated macOS Apple Silicon/CLI combinations, and you need to build from source. Provider accounts and usage costs are separate. The browser version is an interface preview, not an AI execution service.

## FAQ / reply reference

**Is it free?** COI code is Apache-2.0; character assets are CC BY 4.0. Your provider's account and usage charges are separate.

**Does it run offline?** Conversations and working copies are stored locally. Real CLI requests may send code and prompts to the selected AI provider.

**Which computers work?** Live execution is validated only for the macOS Apple Silicon and CLI versions in the support matrix. Intel/Windows builds do not imply live execution support. No signed installer is available.

**Is that Live2D?** The character uses PixiJS with complete-pose images and bounded mesh motion, not Cubism.

**Do stickers run commands?** No. They insert editable request text; you decide when to send it. Existing approval gates still apply.

**Can it edit my project?** It works in a copy. Applying reviewed text changes to originals requires a separate action; conflicting changes stop application or recovery. Read the current limitations before use.

**Where should I ask for help?** After public launch, use a public issue for a sanitized reproducible bug or setup question in English or Japanese. Never post secrets or sensitive reports; use the published security/conduct channel instead.
